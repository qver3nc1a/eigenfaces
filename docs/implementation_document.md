# Implementation document

## Project structure
This repository is organized into documentation, data, tests, and program code the following way:

- data/: images of faces from the olivetti dataset, each in 64x64 format and sorted by person
- centered_faces/: images of centered faces (note! run )
- docs/: project documentation and weekly reports
- src/: program code (jacobi, pca, dataset loader, evaluation on olivetti)
- tests/: automated tests for jacobi and pca

The main program consists of the Jacobi iteration method and a PCA pipeline.

### Jacobi
The Jacobi iteration method for calculating eigenvalues and eigenvectors is implemented in `src/jacobi.py`. It eliminates off-diagonal elements by performing Jacobi rotations until all off-diagonal values are close enough to 0. What "close enough" means is determined by the tolerance (default 10^(-16)). The diagonal values of the diagonal matrix are eigenvalues, and their respective eigenvectors are calculated by performing all the same rotations on an identity matrix.

### PCA
The PCA pipeline uses the eigenvectors calculated with Jacobi to perform face recognition. The core idea is to transform the input face images into a small set of characteristic feature images (eigenfaces), which are the principal components of the initial set of face images. Face recognition is performed by comparing a new face with the representations of the faces in the training set. Here "comparing" means projecting the new face onto a subspace generated by the eigenfaces (face space) and its position with the positions of known individuals.

More detailed steps:
- Images are all concatenated into one matrix A (images are flattened and in A one column is one image)
- The average face is calculated: $Ψ=1/M * \sum_{i=1}^{n} Г_n$
- The average face is subtracted from all faces: $Ф_i=Г_i-Ψ$ -> $A=[Ф_1 Ф_2 ... Ф_n]$
- The covariance matrix is calculated ($C=AA^T$)
- Eigenvalues and eigenvectors ($u$) are calculated (Jacobi)
- Weights are calculated: $w_k = u_k^T*(Г-Ψ)$
- The weight vector is created: $Ω^T=[w_1,...,w_n]$
- Distances between projections and known individuals are calculated: $\Sigma_k=||Ω^T-Ω||$
