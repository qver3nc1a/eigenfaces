## Topic and implementation

### Problem:
The same face can look very differently in different pictures due to differences in lighting, facial expressions, angle, and image quality, making it challenging to reliably distinguish between different people. This project investigates whether the Eigenfaces approach can effectively solve the problem.

### Core of the exercise:
The core of the exercise is to implement a face recognition system using the Eigenfaces approach developed by Sirovich and Kirby and later applied to classification by Turk and Pentland. The system is trained on a set of images of faces and then uses the learned facial features to recognize a person in a new input image.

### Algorithms and data structures:
The main algorithm used is the Eigenfaces algorithm, which is based on Principal Component Analysis (PCA). The core idea is to transform the input face images into a small set of characteristic feature images (eigenfaces), which are the principal components of the initial set of face images. Face recognition is performed by comparing a new face with the representations of the faces in the training set. Here "comparing" means projecting the new face onto a subspace generated by the eigenfaces (face space) and its position with the positions of known individuals.

More detailed steps:
- Images are all concatenated into one matrix A (images are flattened and in A one column is one image)
- The average face is calculated: $Ψ=1/M * \sum_{i=1}^{n} Г_n$
- The average face is substracted from all faces: $Ф_i=Г_i-Ψ$ -> $A=[Ф_1 Ф_2 ... Ф_n]$
- The covariance matrix is calculated ($C=AA^T$)
- Eigenvalues and eigenvectors ($u$) are calculcated (Jacobi)
- Weights are calculated: $w_k = u_k^T*(Г-Ψ)$
- The weight vector is created: $Ω^T=[w_1,...,w_n]$
- Distances between projections and known individuals are calculated: $\Sigma_k=||Ω^T-Ω||$
### Inputs:
Training data is a dataset of images of faces. Each image is associated with the identity of the person in it. A new facial image is then provided to the recognition system, which attempts to identify the person in the image based on already learned persons.
